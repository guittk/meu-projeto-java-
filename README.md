# Projeto Crud + CI/CD

CRUD simples em java puro de filmes.

## O que é testado

O projeto conta com uma cobertura de testes unitários que valida as seguintes operações do `FilmeService`:

1.  **Adicionar Filme**: Verifica se um novo filme é inserido corretamente na lista.
2.  **Listar Filmes**: Garante que a listagem retorna todos os filmes cadastrados.
3.  **Deletar Filme**: Valida a remoção de um filme pelo nome (case-insensitive).
4.  **Listar Detalhes**: Confirma se a busca por nome retorna o objeto completo com `diretor` e `dataLancamento`.
